## 🚀 Como Publicar no GitHub (Apenas 2 Arquivos)

### Passo 1: Criar o Repositório
1. Acesse [github.com](https://github.com/) e clique em **New repository**.
2. Nomeie o repositório como: `minhas-biblias`.
3. Deixe marcado como **Public** e clique em **Create repository**.

### Passo 2: Enviar os Arquivos
1. Na tela do repositório, clique em **Add file** > **Upload files**.
2. Envie apenas estes **2 arquivos**:
   - `index.html` (o arquivo unificado com todo o HTML, CSS e JavaScript)
   - `README.md`
3. Clique em **Commit changes**.

### Passo 3: Ativar o GitHub Pages (Hospedagem Gratuita)
1. No seu repositório no GitHub, clique na aba **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Na seção **Branch**, selecione `main` (ou `master`) e pasta `/(root)`.
4. Clique em **Save**.
5. Aguarde cerca de 1 minuto e seu link estará no ar:
   `https://seu-usuario.github.io/minhas-biblias/`

## 📲 Como Instalar no Celular como Aplicativo Nativo

- **No iPhone / iPad (Safari):**
  Abra o link do site, toque no botão de compartilhar (quadrado com seta apontando para cima) e escolha **"Adicionar à Tela de Início"**. O ícone aparecerá junto aos seus outros aplicativos.
- **No Android (Google Chrome):**
  Abra o link, toque nos três pontinhos no canto superior direito e selecione **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
